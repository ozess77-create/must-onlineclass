1플랫폼 소개

MUST 특목입시센터 온라인 수업 플랫폼은 자소서·면접 1대1 수업과 3대1 모의면접을 관리하는 전용 공간입니다.
구글 계정으로 로그인하면 역할(학생·선생님·관리자)에 맞는 화면이 자동으로 열립니다.

2로그인 방법
1
플랫폼 접속
관리자로부터 받은 링크로 접속하세요. 검정 배경의 로그인 화면이 나타납니다.
2
구글 계정으로 로그인
「구글 계정으로 시작하기」 버튼을 누르면 구글 로그인 팝업이 열립니다.
관리자에게 등록된 구글 계정(Gmail)으로 로그인하세요.
3
역할 자동 판별
로그인 후 내 이메일에 따라 역할이 자동으로 결정됩니다.
 • 관리자 이메일 → 관리자 화면
 • 선생님으로 등록된 이메일 → 선생님 화면
 • 학생으로 등록된 이메일 → 학생 화면
⚠ 로그인이 안 되거나 화면이 이상한가요?
관리자에게 내 구글 계정 이메일을 학생 또는 선생님으로 등록해 달라고 요청하세요.
3수업 시작하기 (수업 입장)
수업은 Google Meet으로 진행됩니다.
플랫폼에서 「수업 입장하기 →」 버튼을 누르면 해당 수업의 Google Meet 방이 바로 열립니다.
📚 1대1 수업
담당 선생님 전용 Meet 링크로 입장합니다.
학생과 선생님 각 1명이 참여합니다.
🎤 3대1 모의면접
면접 전용 공용 Meet 링크로 입장합니다.
학생 1명 + 면접관 선생님 3명이 참여합니다.
학생 — 수업 입장 순서
1
로그인 후 내 화면 확인
로그인하면 오늘 수업이 있을 경우 상단에 파란색(1대1) 또는 청록색(면접) 카드로 강조 표시됩니다.
2
「수업 입장하기 →」 버튼 클릭
오늘 수업 카드에 있는 초록색 버튼을 누르면 Google Meet이 새 탭으로 열립니다.
3
Google Meet에서 수업 진행
카메라·마이크를 켜고 선생님이 입장하면 수업을 시작합니다.
수업 자료(구글 닥스)는 화면 하단 「자료 열기」 링크에서 확인하세요.
버튼 예시 수업 입장하기 → 면접 입장하기 →
선생님 — 수업 입장 순서
1
로그인 후 오늘 수업 확인
선생님 화면에 오늘 수업 목록이 표시됩니다. 수업 건수와 담당 학생을 확인하세요.
2
「내 수업방 입장」 버튼 클릭
상단 통계 영역의 「내 수업방 입장」 버튼을 누르면 내 전용 Google Meet 방이 열립니다.
3
수업 후 출석·피드백 입력
수업이 끝나면 수업 카드의 「피드백·출석」 버튼을 눌러 출석 여부와 피드백을 입력하세요.
입력한 내용은 학생 화면에 즉시 반영됩니다.
4관리자 기능
수업 등록
1
「+ 수업 등록」 버튼 클릭
관리자 화면 → 수업 일정 탭에서 우측 상단의 버튼을 누릅니다.
2
수업 정보 입력
수업 유형 선택 (1대1 수업 / 3대1 모의면접)
학생 선택 → 선생님 선택 (면접은 복수 선택)
수업 일시 입력 → 구글 닥스 링크 입력 (선택)
3
「저장」 버튼 클릭
저장하면 학생·선생님 화면에 즉시 반영됩니다.
수업 수정 · 삭제

수업 일정 테이블에서 각 수업 행 오른쪽의 버튼으로 수정하거나 삭제할 수 있습니다.

수정 수업 정보(일시, 학생, 선생님 등) 변경
삭제 수업 완전 삭제 (확인 팝업 후 진행)
⚠ 삭제 주의
삭제된 수업은 복구할 수 없습니다. 삭제 전 반드시 확인하세요.
학생 · 선생님 등록
  • 학생 등록: 수업 일정 탭 옆 「학생」 탭 → 「+ 학생 등록」 → 이름·이메일·목표학교·담당선생님 입력
  • 선생님 등록: 「선생님」 탭 → 「+ 선생님 등록」 → 이름·이메일·Google Meet 링크 입력
  • 등록한 이메일로 로그인하면 해당 역할의 화면이 자동으로 열립니다.
  • 담당 학생이나 수업이 있는 선생님은 삭제할 수 없습니다. 먼저 학생을 재배정하세요.
5자주 묻는 질문
Q. 로그인했는데 빈 화면이 나와요.
관리자에게 내 구글 이메일이 학생 또는 선생님으로 등록되어 있는지 확인해 달라고 요청하세요.
Q. 수업 입장 버튼이 안 보여요.
오늘 날짜에 등록된 수업이 없으면 버튼이 나타나지 않습니다. 「예정 수업」 섹션에서 수업 일정을 확인하거나 관리자에게 문의하세요.
Q. Google Meet에 입장이 안 돼요.
팝업 차단 설정을 해제하거나, 버튼 옆 링크를 직접 복사해서 주소창에 붙여넣기 하세요.
또는 Google Meet 앱(모바일)을 사용해도 됩니다.
Q. 피드백이 안 보여요.
수업 후 선생님이 피드백을 입력해야 학생 화면에 보입니다. 선생님에게 입력 완료 여부를 확인하세요.
Q. 수업 자료(구글 닥스)가 없어요.
관리자가 수업 등록 시 구글 닥스 링크를 입력하지 않은 경우입니다. 관리자에게 링크 추가를 요청하세요.
